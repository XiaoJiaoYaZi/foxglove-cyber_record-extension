# Test data

`demo.record` is a small, complete Cyber record generated by
`rust/examples/make_demo_record.rs`.

It contains two topics and thirty messages:

- `/demo/point` — `demo.Point` (`x`, `y`, `label`)
- `/demo/status` — `demo.Status` (`ok`, `text`, `count`)

Its timestamps start at `1700000000000000000` ns. Open it in Foxglove after
installing the extension, or inspect it with:

```sh
cargo run --manifest-path rust/Cargo.toml --example inspect -- test-data/demo.record
```

Regenerate it with:

```sh
cargo run --manifest-path rust/Cargo.toml --example make_demo_record -- test-data/demo.record
```
